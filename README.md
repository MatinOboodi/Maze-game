# Maze Game

A simple maze game made with Python and Pygame Zero.

---

## Features

* Player movement with arrow keys
* Collect keys to unlock doors
* Reach the goal to win
* Moving enemy
* Collision detection
* Simple 8×8 maze

---

## Technologies

* Python
* Pygame Zero

---

## Installation

Clone the repository:

```bash
git clone https://github.com/MatinOboodi/Maze-Game.git
cd Maze-Game
```

Install the required library:

```bash
pip install -r requirements.txt
```

---

## Run

Run the game with:

```bash
main.py
```

---

## Controls

| Key         | Action     |
| ----------- | ---------- |
| Up Arrow    | Move up    |
| Down Arrow  | Move down  |
| Left Arrow  | Move left  |
| Right Arrow | Move right |

---

## Goal

Collect the key, unlock the door, avoid the enemy, and reach the goal to complete the maze.
